## 🚀 Getting Started

### Prerequisites

```bash
pip install numpy pandas matplotlib seaborn scikit-learn tensorflow keras opencv-python ultralytics transformers torch
```

### Run Any Notebook

```bash
# Clone the repo
git clone https://github.com/Bala-saran/AI-ML.git
cd AI-ML

# Open any notebook
jupyter notebook "Linear Regression.ipynb"
```

Or open directly in **Google Colab** — recommended for GPU-heavy notebooks (TensorFlow, YOLO).
